# 智能公司客户端（OneCompany Client）

**版本**：v1.0（演示版）
**日期**：2026-10-04
**对应方案**：[OneCompany_Solution.md](./OneCompany_Solution.md)（v2.1，§8 UI界面与交互方式）
**形态**：桌面窗口风格的网页应用（深色控制台质感）

## 项目简介

"一人AI自我进化公司"的智能管理客户端，类似 WorkBuddy 的公司控制台。将方案 §8.1 的六个核心视图落成可交互的桌面窗口应用，用于查看公司运行状态、管理 7 名 AI 员工、跟进任务与审批、查阅资料库与动态日志。

## 6 大核心视图

| 视图 | 路由语义 | 内容 |
|:---|:---|:---|
| **总览** | 公司整体运行状态 | 运行状态灯矩阵、4 项 KPI（运行时间/今日Token/今日收入/待审批）、待办事项、Token 消耗趋势（面积图 + 进度环）、今日动态时间线 |
| **组织** | AI 员工名册 | 7 名 AI 员工卡片（Minion/Sage/Scout/Quill/Xalt/Observer/合规Agent）、状态筛选、员工详情抽屉（模型配置/Token预算/近期任务）、月度 Token 消耗排行 |
| **任务** | 任务看板 | 四列看板（待认领/执行中/待质检/已交付）、任务详情（评论 + 状态流转时间线）、按员工筛选 |
| **审批** | 决策中心 | 审批统计卡、>100 美元强制审批红色标识、批准/驳回操作（含驳回理由）、决策结果本地持久化 |
| **资料库** | 工作文档 | 项目树 + 文档列表、类型/搜索筛选、文档预览抽屉（ACL 权限 + Markdown 渲染） |
| **动态** | 运行日志 | 时间线动态流、按员工筛选、日/周/月 Token 消耗汇总 |

## 桌面窗口风格

- 顶部窗口标题栏（Logo + 窗口控制按钮）
- 左侧导航栏（6 个模块 + 角标计数 + 创始人身份区）
- 底部状态栏（系统状态呼吸灯 + 员工状态分布 + Token 进度 + 实时时钟）
- 深色科技感配色，控制台/指挥中心质感，状态灯与数据面板为主视觉

## 数据与边界

- **当前为演示版**：业务数据（员工、任务、审批、Token 趋势、动态日志）为模拟数据，用于跑通完整交互；
- **本地持久化**：审批的批准/驳回决策结果存储在浏览器本地（换设备/换浏览器不共享）；
- **在线访问**：产物由平台应用托管，入口见交付卡片。

## 后续演进计划
